# SEO setup for SABA

Added:
- SEO title and description in index.html
- SEO title and description in projects.html
- Open Graph tags for social sharing previews
- Twitter card tags
- Schema.org structured data
- robots.txt
- sitemap.xml
- admin.html is marked noindex,nofollow

After deploying:
1. Open https://saba.company/robots.txt and check it loads.
2. Open https://saba.company/sitemap.xml and check it loads.
3. Add the website to Google Search Console.
4. Submit sitemap:
   https://saba.company/sitemap.xml

Important:
Google indexing can take days or weeks. This code helps Google understand the site, but it does not guarantee first-page ranking.
