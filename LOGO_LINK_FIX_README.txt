SABA logo link fix

This version accepts Google Drive sharing links for the header logo.
Example accepted link:
https://drive.google.com/file/d/10JxjUb4dLHPlMlu1Cce01paOK0Kc9FXY/view?usp=drive_link

The website automatically converts it to a displayable image URL.

Important: in Google Drive, set file permission to: Anyone with the link can view.
If the logo still does not appear, run logo_google_drive_fix.sql in Supabase SQL Editor or upload the logo file directly into your website/assets folder and use assets/logo.png.
